Swept on `ui-redesign` at cc3bab7 (2026-10-09, main session): all 85
`Config.Bind` entries in `src/` and every `GUI.Toggle` in the tabs. Result:
**no pair left that can be on together and contradict** - nothing to change.
Each candidate and why it is fine:

| Settings | Why they do not contradict |
|---|---|
| Deaths: *OnDeath* choice, reload with load / in place, skip menu, capture, boss fight | Done in T-0226: one radio for what a death does, a radio for how the reload loads; *QuickLoad\** notes hidden for *GameDeath* |
| Deaths: God mode vs *OnDeath* | God mode stops damage; the death choice applies to any death that still happens - layered, not opposed |

| Runs: *Practice mode* (F9) vs run mode | F9 never touches a run mode run (`RunTiming.ToggleTouchesRun`); the status line says "this run is timed by run mode" |
| Runs: *Compare to*, ghost look, replay view, LiveSplit timing, zone display | Already radios (one choice) |
| Runs: *Auto-restart* vs *Results panel* | The panel closes when the next run's **clock starts** (`ResetSplits`), not at the restart - both on shows the results at the start |
| Runs: *Run lines* off vs line opacity / failed line / ahead-only | Not dead: lines are also drawn by the replay camera (`_camOn`), and the opacity also sets the ghost |
| Info box off vs *Compact* / text size / lines | Not dead: lines can be detached HUD widgets; *Compact* is read by widgets (Inventory, RunInfo, Update) |
| Splits: panel off vs columns | Not dead: the LRT column also sets the results panel's load line |
| Site: *Upload runs* vs *Send attempts* | Different things (practice runs vs run mode attempt codes), each labelled in its own section |
| TAS: *Lock frame rate on replay* vs *Record at fixed 60* | Compatible: a fixed-60 recording replays with its 1/60 steps |
| Performance: *Endgame async for restores* vs *at the vault door* | Separate patches (`EndgameLoader.PatchStream(..., atDoor)`), each its own load path |
| Freecam vs replay camera | Each refuses while the other is on, with the reason ("switch it off first") |
| 100%: collected / missing both off | Two list filters; both off = an empty list, not a contradiction |

Not a contradiction but noted for T-0227's walk-through: options that only
