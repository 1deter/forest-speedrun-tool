## What changed
- `src/Data/KeyText.cs` (new, pure, tested): `With("restart", "R")` ->
  "restart (R)" (just "restart" with no key); `Fill(template, key, unbound)`
  fills a description's `{key}` slot, or gives the unbound text.
- `src/Data/HudLines.cs`: a line can name a hotkey (`KeyId`, `Unbound`);
  *Dump status* names `dump.write`, *Current spot* names
  `practice.goToSpot`; `HudLines.Describe(line, keyName)`.
- `src/Core/HudLineTips.cs` (new): the values' hover tips, one set shared by
  Settings > HUD and Edit HUD; a keyed tip is rebuilt only when its key
  changes (no allocation per pass). `HotkeyMap.Find(id)` added.
- `src/Modules/PracticeModule.cs`: run mode's refusal notice says
  "restart (<the Restart key>)" (was the literal "restart (F7)"); built on
  a refusal only.
