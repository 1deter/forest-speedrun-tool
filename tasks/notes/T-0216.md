# T-0216 Results panel: Escape closes it

Running notes across sessions (docs/harness.md 11a).

- 2026-10-09 (cloud session, branch `cloud/results-escape`): **parked with a
  question, no code changed.** Escape is today the way to reach the results
  panel's buttons, and in run mode the only way:
  - The panel's buttons (Restart, Close, Copy link) show only while the cursor
    is the runner's: the F2 window or the game's pause menu
    (`PracticeRunModule.Results.cs`, `RefreshResults` -> `_resClickable`). Its
    hint says so: "ESC (pause menu) or F2 for the buttons."
  - In run mode the F2 window opens only over the pause menu
    (`ModuleHost.RunWindowAllowed`: "Run mode: press ESC first - during a run
    the window opens over the pause menu."), and run mode stays active after an
    attempt finishes (`RunMode.Active`: from a run start until End). So the run
    mode panel's Copy link (the attempt page) and Restart are reachable only
    through ESC.
  - If ESC closes the panel on the same press that opens the pause menu, a run
    mode runner can never click those buttons; in practice F2 still reaches them.
  - The game's pause menu would still open on that press either way: the plugin
    reads Escape raw (`Input.GetKeyDown`, as the replay camera already does in
    `PracticeRunModule.Camera.cs`), which Rewired does not consume, and keeping
    the game from reacting would need a patch into its input - not done without
    asking.

  **Question for the author:** which of these?
  1. ESC closes it at once, practice and run mode alike. Run mode loses the
     panel's buttons (Copy link, Restart); the hint drops "ESC (pause menu)".
  2. ESC closes it at once in practice (F2 still gives the buttons); in run mode
     ESC keeps opening the pause menu with the buttons, as today.
  3. The ESC that **leaves** the pause menu closes it: the first ESC opens the
     menu with the panel's buttons, as today; the next ESC (back in the game)
     closes the panel. Same in both modes, nothing lost - but it is the second
     press, not the first, that maks asked for.
  4. As 3 in run mode, as 1 in practice.

  Recommendation: 4 (or 2). maks's ask is met in practice, and run mode keeps
  its only route to the attempt's link. Whatever is chosen, the hint text
  ("ESC (pause menu) or F2 for the buttons...") changes with it - its new
  words are the author's too.

  Also to confirm: no close on ESC while an overlay panel (F2 window) is open -
  ESC there cancels a key rebind and the panel's Close button is in reach (the
  replay camera's ESC has the same guard). The close gets one log line
  (`Results panel closed (Esc).`), and the Close button and the close key could
  log the same way (`(Close button)`, `(key)`) - they log nothing today.
