## Second round (2026-10-10)

- Remove: all three - erase (hold, near the crosshair), undo (press, last stroke), Clear all.
- Keys: hold to paint (an F-key is uncomfortable). Defaults: paint **Mouse 4**, erase **Mouse 5**, undo **Z** (if the game leaves Z free - check live). All rebindable.
- Colour + size adjustable in Settings: **8 swatches** + a size slider.
- No spot selected: paint is kept for the **session only**.
- Z is the game's `RestKey` (Rewired Default keyboard map; bridge 2026-10-10) -> undo defaults to **X** (author). The game's mouse maps use only the X / Y axes, the wheel and the left / right buttons: Mouse 4 / 5 are free.
