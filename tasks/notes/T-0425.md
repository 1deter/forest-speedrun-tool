# T-0425 Quick load: a kept animal's health is not put back (a rabbit hurt to 1 of 4 stays at 1 after the restore)

Running notes across sessions (docs/harness.md 11a).

- 2026-10-18: Researched live (forest-researcher, bridge, v0.24.358, Slot 1 Creative): health, skin damage and poison of a kept animal all survive a Quick load; build plan below. Game facts: docs/game-notes.md *An animal's health, hurt skin and poison*.

## Cause (proved live, 2026-10-18, v0.24.358, Slot 1, at (428, 78, -4))

`animalHealth` (on the animal's root, `rabbitGo(Clone)00n` from the
creatures pool) is not in the save, and a Quick load touches none of it.
T-0415 keeps the animal object, so whatever happened to it since the
capture stays. Captures `t425a` / `t425b` / `t425c`, then changes made over
the bridge, then `restore`:
- `Health`: rabbits at 4 set to 1 and 2 -> still 1 and 2 after the restore,
  same handles. Writing it back works: `set Health 4`, `Hit 3` gave `Alive`,
  1 left.
- Hurt skin: `ApplyAnimalSkinDamage 0` x2 + `2` -> `_Damage1` 1, `_Damage3`
  0.5 in `mySkin`'s property block, still there after the restore (read
  back fresh: `ApplyAnimalSkinDamage 1` fetches the block, then `GetFloat`).
  `ResetSkinDamage` zeroes all four.
- Poison: `Poison()` after the capture -> still `IsInvoking HitPoison` after
  the restore, health 16 -> 13 within 7 s. `CancelInvoke HitPoison` +
  `disablePoison` stopped it (no loss over 7 s).
- (Already handled: fire since the capture, T-0419 `PutOutAnimals`.)

## Fix (build plan, forest-dev)

Mirror rule (decisions.md, 2026-10-18): a kept animal gets back its health,
hurt skin and poison state as at the capture.

### 1. Pure: `src/Data/AnimalStates.cs` + `tests/.../AnimalStatesTests.cs`
The savestate's `animals` line: one entry per live animal at the capture,
`id:health@d1,d2,d3,d4[@p]`, joined by ';'. `id` = the root GameObject's
instance id, `health` an int, `d1`-`d4` the `_Damage1`-`_Damage4` floats
(invariant culture, "R" or 3 decimals), `@p` when it was poisoned
(`IsInvoking("HitPoison")`). Format / Parse (bad entries dropped, like
`LitFires.Parse`), and the note (`animals: N put back (health x2, skin x1,
poison stopped x1)`; "" when nothing changed). Tests: round trip, invariant
culture under a comma culture, empty / garbage line, an entry without `@p`.

### 2. `SavestateFile`: the `animals` line
Written when non-empty, parsed (`case "animals"`), copied in `Copy()`,
documented in the header comment (absent before T-0425: then animals are
left as they are). `SavestateFileTests`: round trip, absent -> null.

### 3. `src/Game/AnimalKeeper.cs` (reflection only here)
- Resolve `animalHealth` (`GameBridge.FindGameType`), its fields `Health`
  (public int) and `mySkin` (public Renderer). Missing -> one warning, the
  keeper does nothing.
- `Capture()`: `Object.FindObjectsOfType(animalHealth)` (active only - a
  dead animal's root is inactive); for each, the root's id, `Health`, the
  four floats (`mySkin.GetPropertyBlock(block)`, `block.GetFloat`; 0s when
  `mySkin` is null), `IsInvoking("HitPoison")`. Called in SavestateModule's
  capture case 7 (beside `_fire.Capture()`), into a new `p.Animals` / `f.Animals`.
- `Restore(line, sameWorld)`: only when `sameWorld` (the file's `spawned`
  mark gives a real threshold: `SpawnMark.Threshold(file.Spawned,
  NatureKeeper.WorldKey()) < 0`; the key includes the launch, so ids
  of another launch or world are never used). Map the live `animalHealth`s by
  root id; for each entry whose id is live and active:
  - `Health` differs -> set it (count health);
  - any float differs -> `GetPropertyBlock`, `SetFloat` x4,
    `SetPropertyBlock` (count skin);
  - not poisoned at the capture but `IsInvoking("HitPoison")` or
    `("disablePoison")` -> `CancelInvoke` both (count poison).
  Poisoned at the capture: left as it is (the game keeps no time left,
  same as T-0424's fire).
- In SavestateModule's Quick-load done block, right after
  `_fire.Restore(...)` (fire's `cancelFire` does not touch `Health`), the
  note appended to the restore line as `| animals: ...`. A Full load needs
  nothing (it rebuilds the world; animals respawn fresh).
- If a new log prefix appears: `python scripts/log-catalogue.py` +
  `docs/log-lines.md` Meaning line.
