# Logs in the inventory - QA list, v0.24.135, 2026-09-27

Posted in #general (bot):
https://discord.com/channels/1553092607134011542/1553092608509874318/1553724217869078670
(not in `qa/*.txt` - add it to the QA tab with a later release if wanted).

What each item checks (`Game/LogStore`; everything else was confirmed
over the bridge, docs/confirmed.md):
1. The transpiled `LogHolder.Update` / `MultiHolder.LogContentUpdate`
   reads (`HolderAmount`: 2 when full, 1 with room, 0 empty) - add from
   the store, take into it, taking refused when full.
2. `Craft_Structure.AddIngredient` -> `RemoveItem(78)` -> `PutDown`
   prefix, and the blueprint's availability check through
   `AmountOfNF` / `OwnsNF`.
3. `RepairTool` (`Owns(78)` / transpiled `HasLogs`) and `BuildingRepair`.
4. `Amount` / `HasLogs` answering "arms empty" to the forced drops
   (rope top, zipline, bench, `FallDownDead`) - stored logs stay.

```
1) Put stored logs onto a log sled or a log holder (the usual button while looking at it), then take them back off. The count should go down and up, and taking stops when the store is full.
2) Place a blueprint (a wall, a shelter) and add logs to it with logs stored. It should take them from the store.
3) Repair a damaged building with stored logs. It should take them from the store.
4) With logs stored, climb a rope, ride a zipline, sit on a bench or die. The stored logs should stay (the count unchanged, nothing dropped).
```
